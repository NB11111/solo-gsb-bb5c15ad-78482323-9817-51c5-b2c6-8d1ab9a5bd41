# 无人机电池循环健康评估

无需账号的 Web 应用：导入无人机飞行日志 CSV，自动识别充放电循环并评估电池健康。
后端 FastAPI + SQLite，前端为原生 HTML/JS（Canvas 图表，无前端框架），通过 8000 端口访问。

## 功能

- **电池档案**：设置额定容量 (Ah) 与安全电压范围 (V)，可随时修改
- **日志导入**：上传包含 `时间 / 电压 / 电流 / 温度` 四列的 CSV（自动识别常见中英文列名与分隔符）
- **循环识别**：三态状态机（静置 / 放电 / 充电）划定循环边界，自动合并瞬时噪声段
- **容量估算**：梯形库仑积分计算每循环容量 (Ah) 与能量 (Wh)
- **内阻估算**：利用负载加载/卸载瞬间的电压跳变与静置段电压恢复估算直流内阻 (mΩ)
- **异常判定**（均附可解释的依据片段）：
  - 容量突降：相邻放电循环容量下降超过阈值
  - 异常发热：最高温度 / 单循环温升超阈值
  - 未闭合循环：日志结束时仍处于充/放电状态
  - 过放 / 过压：电压超出用户设定的安全范围
  - 单体失衡：单体压差连续超过 0.10V 达 5 秒（短暂尖峰不告警）
- **单体电压分析（可选列）**：按编号成组解析各单体电压，逐循环给出最大压差、
  持续超差时长与证据片段；缺值/单体数漂移仅跳过该行的单体分析
- **趋势摘要**：SOH（最佳容量/额定容量）、近期衰减、每循环衰减率、健康等级
- **JSON 导出**：按电池一键导出完整评估结果（含循环级单体压差与告警区间）

## 快速开始

### Docker Compose（推荐）

```bash
docker compose up --build
```

访问 <http://localhost:8000>。SQLite 数据库持久化在 `battery-data` 卷中，
容器启动时自动完成依赖安装（构建阶段）与 SQLite 初始化（应用启动钩子）。

### 本地运行

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

数据库默认写入 `./data/battery.db`，可用环境变量 `BATTERY_DB` 覆盖。

### 演示数据

```bash
python3 scripts/generate_sample.py   # 生成 sample_data/sample_flight_1.csv 与 _2.csv
```

在页面中新建电池（例如：额定容量 `2.2` Ah，安全电压 `19.8` ~ `25.2` V），
依次上传两份 CSV 即可看到循环识别、容量衰减、异常发热、未闭合循环与单体失衡标记。
两份样例均含 6 个单体列：样例 1 为英文表头且单体一致（放电段含一次约 2s
压差尖峰，不告警）；样例 2 为中文表头，第 4 号单体持续偏弱、放电中段有
3s 采样断点（连续区间被中断为多段），前置静置段还包含单体缺值行与列数
漂移行（仅跳过该行单体分析）。

## CSV 格式

```csv
time,voltage,current,temperature
2026-09-20T10:00:00+00:00,25.11,0.0,26.0
2026-09-20T10:00:01+00:00,25.10,8.1,26.1
```

- **time**：ISO 8601 时间戳或数值秒（也接受 epoch 秒/毫秒级时间戳）
- **voltage**：电池包电压，单位 V
- **current**：电流 A，**放电为正、充电为负**
- **temperature**：温度 °C
- 列名支持常见别名（time/timestamp/时间、voltage/v/电压、current/i/电流、temp/temperature/温度 等），
  分隔符支持逗号 / 分号 / 制表符，编码支持 UTF-8 / GBK

### 可选：单体电压列

在上述四列之外，可附加**编号连续**的单体电压列（编号从 1 开始）：

```csv
time,voltage,current,temperature,cell1_voltage,cell2_voltage,cell3_voltage
2026-09-20T10:00:00+00:00,12.55,0.0,26.0,4.182,4.185,4.183
```

支持的列名格式（自动忽略 `(V)`、空格、大小写差异）：

| 风格 | 示例 |
| --- | --- |
| 英文 | `cell1_voltage`、`cell2_voltage`、`cell3v`、`cell4`、`Cell5_Voltage`、`cell-6`、`v1`、`c2` |
| 中文 | `单体1电压`、`单体电压2`、`电芯3电压`、`单芯4电压`、`单体5`、`第1节电压`、`第2串单体电压`、`电压3` |

解析规则：

- 同一数据行内各单体**按编号成组**取压差 `max(cell) − min(cell)`；
- 表头缺少某编号（如只有 cell1、cell3）或编号重复时，不启用单体分析，
  总压循环分析不受影响，并在导入结果中记录原因；
- 某行**单体缺值**（空单元格）、数值无法解析或**列数漂移**（多于/少于声明的
  单体数）时，跳过该行的单体分析并记录原因（按原因计数 + 行号示例），
  该行的总压/电流/温度仍正常参与循环识别；
- 全部行都没有有效单体值时，等同于日志不含单体列。

### 单体失衡判定规则

- 压差阈值 **0.10 V**（严格大于才计为超差，恰好 0.100V 不告警）；
- 超差必须**连续持续 5 秒**才生成 `CELL_IMBALANCE` 标记：短暂尖峰
  （如负载突变造成的 1–2s 抖动）只计入循环最大压差，不产生告警；
- 时长按**时间戳累计**（相邻有效单体采样点的时间差之和），采样间隔
  不规则时同样适用，而非按采样点数折算；
- 相邻两个有效单体采样点间隔**超过 2 秒**（采样断点，或断点区间内单体
  行缺值）时连续区间中断，断点两侧不拼接；
- 每个识别出的循环输出：`max_cell_spread_v`（循环内最大压差）、
  `over_threshold_s`（超差累计时长）与 `cell_intervals`（每个 ≥5s 持续
  区间的起止时间、时长、最大压差点的各单体电压证据片段，以及区间结束
  原因：回落 / 采样断点 / 循环结束）。
- 日志详情图表叠加各单体电压曲线（右侧独立刻度），红色高亮为持续超差
  的单体失衡区间。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| POST | `/api/batteries` | 新建电池（额定容量、安全电压范围） |
| GET | `/api/batteries` | 电池列表（含日志数、放电循环数） |
| GET / PATCH / DELETE | `/api/batteries/{id}` | 查询 / 修改 / 删除电池 |
| POST | `/api/batteries/{id}/logs` | 上传 CSV 并完成循环分析（multipart） |
| GET | `/api/batteries/{id}/logs` | 该电池的日志列表 |
| GET / DELETE | `/api/logs/{id}` | 日志详情（样本 + 循环）/ 删除 |
| GET | `/api/batteries/{id}/assessment` | 汇总评估（摘要、标记、趋势、循环明细） |
| GET | `/api/batteries/{id}/export` | 下载评估 JSON 文件 |

交互式 API 文档：<http://localhost:8000/docs>

## 判定规则与阈值

阈值常量集中在 `app/analysis.py`，可按机型调整：

| 规则 | 默认值 |
| --- | --- |
| 静置电流阈值 | max(0.05 A, 峰值电流 × 3%) |
| 最短循环时长 / 最短静置间隔 | 20 s / 10 s |
| 容量突降告警 / 严重 | 相邻放电循环 −10% / −25% |
| 温度告警 / 严重 | 45 °C / 60 °C |
| 单循环温升告警 | 15 °C |
| 电压越限余量 | 0.02 V |
| 单体压差超差阈值 / 最短持续时长 | 0.10 V / 5 s |
| 单体连续区间采样断点 | 间隔 > 2 s 中断 |
| 健康等级 | 综合严重标记数、SOH（<60/70/85%）与衰减率分档 |

**内阻估算**：放电段起点取段前静置电压与加载后电压之差除以负载电流，
终点取静置恢复电压与卸载前电压之差除以卸载电流，两处估计取平均；
充电段取相反符号，结果以 mΩ 展示。

## 项目结构

```
app/
  main.py        FastAPI 路由与启动钩子（启动时初始化 SQLite）
  database.py    SQLite 连接与建表
  analysis.py    状态机循环识别、库仑积分、内阻估算、单体压差分析、判定与汇总
  importer.py    CSV 解析（列名别名、单体列识别、分隔符嗅探、时间归一化）
  static/        原生前端（index.html / app.js / style.css）
scripts/generate_sample.py   演示数据生成器
Dockerfile / docker-compose.yml
```
